Batch File Copy / Move

Paste banyak alamat file lokal dari Excel, pilih folder sumber yang memberi izin browser, pilih folder tujuan, lalu Copy atau Move secara batch.
Keamanan browser: alamat C:\ tidak dapat diakses hanya dari teks. Pilih Source Root sekali untuk memberi izin ke folder sinkronisasi. Semua proses file berlangsung lokal di browser dan tool ini tidak mengunggah file.

1. Paste alamat file

Paste satu kolom dari Excel. Satu baris = satu alamat file lengkap, misalnya C:\YDS\...\OP 7887331.pdf. Jika Anda menyalin beberapa kolom, tool mencoba mengambil cell yang berisi Windows path.

ImageKit URL Manager

Gabungkan URL gambar dari satu atau seluruh akun ImageKit, termasuk semua folder dan subfolder.
Keamanan: Private API Key setiap akun hanya disimpan di Supabase Edge Function secrets. Gunakan satu Tool Access Token untuk mengakses akun yang terdaftar. Jangan menaruh Private API Key di halaman ini.

1. Koneksi aman

Pengaturan backend satu kali. Token akses disimpan di memori halaman saja, tidak di localStorage.

—

2. Ambil URL gambar

Pilih satu akun atau semua. Seluruh folder dan subfolder dibaca otomatis tanpa memasukkan path folder.

Jika satu akun gagal, hasil akun lain tetap ditampilkan dan akun yang gagal dilaporkan. Hasil parsial tidak dianggap ekspor lengkap.

Siap. Masukkan Tool Access Token lalu klik Fetch All Image URLs.
